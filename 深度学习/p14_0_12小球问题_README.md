# 12小球问题求解演示

## 问题描述

有12个外表看起来一模一样的小球，其中11个重量完全相同，1个重量不同（可能较重或较轻，但不知道具体是哪种）。使用天平秤**3次**可以找出这个坏球，并确定它是较重还是较轻。

## 解决方案

本脚本实现了完整的12小球问题求解算法，并通过Tkinter动画演示求解过程。

### 算法核心思路

#### 第一次称重：比较球1-4 和 球5-8

1. **如果平衡**：坏球在球9-12中，进行下一步
2. **如果不平衡**：坏球在球1-8中，记录哪边重

#### 第二次称重：根据第一次结果进行

**情况A：第一次平衡**
- 比较球9,10,11 和 球1,2,3（已知正常）
- 结果分析：
  - 平衡 → 坏球是球12
  - 左盘重 → 坏球在9-11中且较重
  - 右盘重 → 坏球在9-11中且较轻

**情况B：第一次左盘重**
- 比较球1,2,5 和 球3,6,9（已知正常）
- 结果分析：
  - 平衡 → 坏球在4,7,8中
  - 左盘重 → 坏球在1,2中（重）或6中（轻）
  - 右盘重 → 坏球在5中（重）或3中（轻）

**情况C：第一次右盘重**
- 对称处理情况B

#### 第三次称重：确定具体球号和重量特征

根据第二次的结果，针对性地进行最后一次称重，精确找出坏球。

## 原理解释

这个问题的关键在于：
1. **信息最大化**：每次称重都要获取尽可能多的信息
2. **状态追踪**：记录每种称重结果对应的可能状态
3. **分治法**：将大问题分解为小问题逐步求解
4. **排除法**：通过已知信息缩小搜索范围

3次称重可以区分 3^3 = 27 种状态，而12个球 × 2（重/轻）= 24 种可能，因此3次称重足够。
