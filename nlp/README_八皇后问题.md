# 八皇后问题求解器 (优化美化版)

## 📋 项目概述

这是一个使用Python实现的**八皇后问题求解器**，采用**回溯算法**系统地搜索所有92个唯一解，并以**彩色美化**的方式展示结果。

## 🎯 问题描述

**八皇后问题**是国际象棋中的经典问题：

> 在8×8的国际象棋棋盘上放置8个皇后，使得任意两个皇后都不能互相攻击。

**攻击规则：**
- 皇后可以攻击**同一行**、**同一列**、**同一对角线**上的所有格子
- 因此8个皇后必须满足：不在同一行、不在同一列、不在同一对角线

## 🔧 技术特点

### 1️⃣ **核心算法：回溯法 (Backtracking)**

```
从第1列开始，逐列尝试放置皇后：
  对于每一列(col)：
    尝试每一行(row)：
      如果当前位置安全(is_safe)：
        放置皇后
        递归处理下一列
        如果后续无法完成：
          回溯（移除皇后，尝试下一行）
      如果所有位置都不安全：
        返回上一列继续搜索
```

### 2️⃣ **安全检查函数**

```python
is_safe(board, row, col)
```

检查三个方向：
- ✅ 左侧同一行是否有皇后
- ✅ 左上方对角线是否有皇后
- ✅ 左下方对角线是否有皇后

### 3️⃣ **彩色美化显示**

- 使用**ANSI颜色代码**实现彩色输出
- **紫色/蓝色背景**高亮皇后位置
- **交替背景色**模拟真实棋盘格
- **边框和分隔线**增强可读性
- **Unicode皇后符号** (♛) 美观展示
